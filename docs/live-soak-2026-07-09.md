# 1-hour live soak — 2026-07-09 (Iter 21-web default)

Browsed ~93 page-loads across a broad site mix (news/tabloid, sports, recipe,
shopping, social, video, SPA, EU-consent) with opt-in collection ON, reviewing
captures live and fixing bugs as they surfaced.

## Precision by domain
- **Trained domain (news / tabloid / sports / recipe): ~80%** — clean single-slot
  ad crops (Baker Tilly, Benjamin Moore, Bill4Time, Taboola sponsored rows,
  movie-ticket ads).
- **Out-of-domain (shopping / social / video): low precision, but LOW volume.**
  The gates keep volume down (Amazon +4, Reddit +4, Etsy +0 overlays) but the
  few flagged are **model-level** FPs on ad-*shaped* content:
  - shopping product listings (eBay/Amazon ~227×227 ≈ standard 250×250)
  - Pinterest pins (278×556, skyscraper-shaped)
  - YouTube thumbnails (500×281, 16:9)
  - subscribe/paywall promos (El Mundo), some cookie-consent banners

These are the known Iter 21-web limitation (product-on-white holdout is 0.5%,
but real product *listings* + editorial images trigger it). Not an extension
gate failure — the crops are correct single elements; the model mis-scores them.

## Bugs found + fixed this soak (all committed)
1. **Upload backoff too aggressive** for scale-to-zero cold start → gentle 20s
   ramp + 25s timeout.
2. **Scale-to-zero cold-start** upload failures → ingest server now **always-on**
   (min 1 machine).
3. **Large-batch POST timeouts** with a big queue → smaller 6-crop batches.
4. (via E2E) **AD_HINT boundary regex** excluded whitespace → id ending in
   `-ad` (e.g. `shadow-ad`) missed ad-context.

## Residual / future work
- **Model FPs on out-of-domain product/editorial/video content** — collect via
  the opt-in pipeline (now running) and fold into a future training iter as
  non-ads (shopping listings, social pins, video thumbnails).
- **Consent/paywall banners** — `isConsentUI` misses class-less banners; add
  text-based detection ("Agree" + "Terms/Privacy/cookies") with care not to
  over-match real ads.
- **Candidate extension tweak:** require ad-context for bare `<img>` even at
  standard sizes (would cut shopping-listing FPs) — validate recall impact on
  the trained domain first (real news-site ads mostly have ad-context, so the
  hit should be small).
